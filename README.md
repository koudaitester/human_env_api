## 🚀 核心业务运行流程（霉菌检测主链路）
1. 前端上传室内实景照片；
2. 后端调用RAG检索，匹配对应的潮湿、霉菌判定行业规则；
3. 将图片+检索到的业务规则一同送入MoonDream视觉模型；
4. 模型输出目视隐患，再叠加温湿度参数做加权计算，自动生成风险等级、隐患位置、整改建议；
5. 结构化结果直接返回前端，形成可存档的检测结论。

> 其余链路：设备规则校验、本地LLM对话、视频生成异步任务，均已完成接口与页面打通。
