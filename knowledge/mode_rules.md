# 人居微环境 - 霉菌风险评估知识库
> 用于RAG检索，配合图像识别、温湿度参数，完成霉菌风险综合评估

## 一、基础判定阈值（温湿度参数）
1. 相对湿度 RH ＜ 55%：霉菌生长条件抑制，低风险。
2. 相对湿度 RH ≥ 55%：满足霉菌萌发基础条件，**初级霉菌风险**；
3. 相对湿度 RH ≥ 65%：适宜霉菌快速繁殖，中风险；
4. 相对湿度 RH ≥ 75%：极易滋生霉菌，高风险。

> 说明：温度 18℃～28℃ 是霉菌最适宜生长区间。在此温度区间内，叠加高湿度，风险等级上调一档。

## 二、图像视觉线索（无温湿度数据时，仅靠图片推断）
### 视觉正向线索（存在霉菌迹象）
- 墙面/墙角、窗框四周、浴室瓷砖缝隙、吊顶边角出现黑/灰/绿色斑点、片状斑块
- 墙皮起皮、鼓包、渗水留下的深色水渍印
- 玻璃、金属表面持续冷凝结露、有水珠流淌痕迹
- 柜体背面、床底等阴暗死角长期潮湿

### 视觉环境线索（未见霉斑，但存在潜在风险场景）
- 北向房间、无外窗密闭空间，采光差、空气流通弱
- 靠近水管、外墙、地下室墙面
- 室内堆放大量织物、纸箱，紧贴墙面，阻挡空气流通

### 视觉排除线索（大概率不是霉菌）
- 浮尘：擦拭即可擦掉，无渗透进墙体痕迹
- 普通污渍：溅落的泥点、油污，形态边界清晰，无扩散蔓延

## 三、综合评估逻辑
1. 方案A：仅图片输入
    仅依靠视觉特征，**只能判断表面可见霉斑或可疑潮湿场景**。无法判定墙体内部、板材内部隐藏霉菌。若图片未见霉斑，仅识别到密闭阴暗/冷凝水渍，输出提示：存在潜在风险，建议补充温湿度监测。
2. 方案B：图片 + 温度 + 相对湿度（推荐完整评估）
    - 第一步：LLaVA图像识别，输出视觉观察结果
    - 第二步：RAG检索本知识库规则
    - 第三步：融合视觉结果 + 温湿度，综合定级
    - 风险等级：低风险 / 初级风险 / 中风险 / 高风险

## 四、处置建议库
- 低风险：保持常规通风，定期监测温湿度即可。
- 初级风险：加强每日通风，控制室内湿度低于55%，检查冷凝水源。
- 中风险：增加空气净化/除湿设备，清理角落杂物，减少藏湿物品靠墙摆放。
- 高风险：优先除湿，对可见霉斑做消杀处理；墙内渗水需修复水源，必要时专业检测。

## 五、重要免责提示
本评估为AI辅助筛查工具，**不能替代专业CMA环境检测**。图片只能观察表面，墙体夹层、板材内部隐藏霉菌无法通过照片识别。
