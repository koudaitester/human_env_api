# 霉菌风险评估计算规则

> 版本：v0.1
> 目标：基于多因子加权评分，输出【1条核心操作 + 2条辅助建议】
> 适用范围：室内人居微环境霉菌风险预判

---

## 一、权重分配（总分100）

| 因子 | 权重 | 说明 |
|---|---|---|
| **室内整体相对湿度** | **40%** | 最核心决定因子。>60%孢子快速繁殖，>70%高风险 |
| **建筑局部高湿点位** | **30%** | 厨卫潮气、墙体渗水、窗台结构缺陷、保温层失效。局部持续潮湿是最易被忽略的强诱因 |
| **季节/时间因素** | **20%** | 北方冬季密闭采暖、梅雨季、秋雨高湿期，放大发霉风险 |
| **室外气象条件** | **10%** | 仅用于判断开窗策略。室外湿度>室内时禁止开窗 |
| 临时产湿场景 | 动态叠加 | 洗澡/做饭/晾衣，命中时临时拉高风险，不占基础权重 |

---

## 二、各因子评分细则

### 1. 室内整体相对湿度（40分满分）

| 湿度区间 | 得分 | 判定 |
|---|---|---|
| <50% | 0~10 | 安全 |
| 50%~60% | 10~20 | 预警 |
| 60%~70% | 20~32 | 高风险 |
| >70% | 32~40 | 极高风险 |

### 2. 建筑局部高湿点位（30分满分）

| 状态 | 得分 |
|---|---|
| 无局部潮湿点，厨卫排风正常 | 0~5 |
| 厨卫偶有潮湿，排风一般 | 5~15 |
| 厨卫常年潮湿/窗台有结露/墙面有渗水痕迹 | 15~25 |
| 已见霉斑/墙体持续返潮/保温失效 | 25~30 |

### 3. 季节/时间因素（20分满分）

| 场景 | 得分 |
|---|---|
| 干燥通风季节（北方春秋） | 0~5 |
| 一般过渡季 | 5~10 |
| 梅雨季/南方回南天 | 10~16 |
| 北方冬季密闭采暖期 | 10~18 |

### 4. 室外气象条件（10分满分）

| 状态 | 得分 | 说明 |
|---|---|---|
| 室外干燥，适合开窗排湿 | 0~3 | 可通风 |
| 室外湿度与室内持平 | 3~6 | 通风效果有限 |
| 室外湿度>室内，通风会恶化 | 6~10 | **禁止开窗** |

### 5. 临时产湿场景（动态±10分修正）

| 命中 | 修正 | 配套动作 |
|---|---|---|
| 正在洗澡/做饭 | +8~10 | 关闭厨卫门，开启排风 |
| 室内晾衣 | +5~8 | 集中在小空间，加强排风 |
| 刚洗完大量衣物 | +3~5 | 及时烘干 |

---

## 三、总分判定与输出

### 风险等级

| 总分 | 等级 |
|---|---|
| <30 | 安全 |
| 30~50 | 预警 |
| 50~70 | 高风险 |
| >70 | 极高风险 |

### 输出格式（固定模板）

✅【核心操作】最高权重因子对应的对策（必须现在执行）
📌【辅助建议 1】第二优先级动作
📌【辅助建议 2】第三优先级动作


### 冲突处理规则

- **方向优先于执行**：室内想降湿要开窗，但室外湿度更高 → 直接否决开窗方案，改用室内除湿。
- **局部优先于整体**：全屋湿度合格，但厨卫已见霉斑 → 核心操作指向局部治理，而非全屋除湿。
- **临时叠加**：洗澡/做饭场景触发时，核心操作临时切换为"关门+排风"，结束后恢复基础评估。

---

## 四、示例

**场景**：北方冬季，室内湿度65%，卫生间通风差且墙角有旧霉斑，室外湿度75%。

| 因子 | 得分 |
|---|---|
| 室内湿度65% | 26 |
| 卫生间局部潮湿 | 22 |
| 冬季密闭 | 14 |
| 室外湿度75%>室内 | 8 |
| **总分** | **70（极高风险）** |

**输出**：

✅【核心操作】开除湿机 / 空调除湿，目标将室内湿度降至 60% 以下
📌【辅助建议 1】卫生间保持关门，洗浴后开排风 15 分钟，擦干墙面
📌【辅助建议 2】当前室外湿度偏高，禁止开窗通风
