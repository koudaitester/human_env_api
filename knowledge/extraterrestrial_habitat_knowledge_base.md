# 地外人居环境评估知识库.md
> 说明：本知识库用于多模态视觉评估系统扩展，支持火星、木卫二、土卫六场景，可接入RAG，配合图像+环境参数做综合风险判断。所有场景描述为天体原生自然环境；舱内人造环境单独一套规则。

## 宇-火星（Mars）
### 基础环境参数
- 大气：极稀薄，主要为CO₂，气压约0.6 kPa（地球海平面约101kPa）
- 地表温度：-153℃ ~ +20℃，平均约 -63℃
- 辐射：银河宇宙射线+太阳高能粒子，地表无磁场、薄大气，强电离辐射
- 水：地下冰层；地表干燥，几乎无液态水
- 土壤：高氯酸盐，有毒，粉尘极细，易磨损设备、侵入密封结构
- 重力：0.38g

### 环境风险清单
1. 低压：无压力舱，人体体液沸腾，瞬间失压致死
2. 极端低温：快速冻伤，设备保温/散热难度大
3. 宇宙辐射：长期暴露致癌，破坏电子器件
4. 火星尘：腐蚀性、磨损密封件，吸入有毒
5. 无液态自由水：原生环境无法支持地球型微生物/霉菌生长
6. 昼夜温差巨大：舱体外壁热应力反复形变

### 评估判定规则
- 原生火星地表：**霉菌风险：无**
- 若密闭舱内：独立控制温湿度，遵循地球人居规则（20~25℃，RH45~55%），舱内才会存在霉菌风险
- 视觉识别重点：舱体破损、密封裂隙、粉尘堆积、隔热层老化、辐射屏蔽结构缺损

## 神-木卫二（Europa）
### 基础环境参数
- 大气：极稀薄，几乎只有氧气（来自冰面辐解），气压极低
- 表面：厚冰层（10–30km），冰层下方存在巨大液态咸水海洋
- 地表温度：约 -160℃
- 辐射：木星强辐射带，冰层表面辐射极强
- 重力：0.13g

### 环境风险清单
1. 表面极低温，冰层坚硬
2. 木星磁层高能粒子轰击，表面辐射极强
3. 冰壳存在冰震、冰裂缝，地质活动
4. 地下海洋存在液态水，但含盐，且无氧气
5. 地表无液态水，冰面环境不滋生霉菌

### 评估判定规则
- 冰面原生环境：**霉菌风险：无**
- 潜在风险点：冰壳开裂、着陆器地基失稳、外部管线冻裂
- 视觉识别重点：冰裂隙、着陆平台倾斜、外壳结冰堆积

## 大-土卫六（Titan，泰坦）
### 基础环境参数
- 大气：太阳系唯一拥有浓厚氮气大气的卫星，气压≈147kPa（高于地球）
- 大气成分：N₂为主，少量甲烷
- 地表温度：约 -179℃
- 液体：地表存在液态甲烷/乙烷湖泊，**没有液态水**（水在土卫六为坚硬冰岩）
- 重力：0.14g

### 环境风险清单
1. 极低温，甲烷循环（甲烷雨、甲烷湖泊）
2. 有机气溶胶浓雾，能见度低
3. 低温下材料脆化，密封件容易失效
4. 液态甲烷有溶解、浸润风险
5. 不存在液态水，原生环境无法生长地球霉菌

### 评估判定规则
- 土卫六地表原生环境：**霉菌风险：无**
- 视觉识别重点：浓雾遮挡、低温材料裂纹、甲烷液体浸润痕迹、沉积物堆积

## 迦-通用天体基础约束
### 通用规则（地外天体统一）
1. 霉菌判定核心前提：**必须同时存在液态水 + 适宜温度（0~40℃）**。火星/木卫二/土卫六原生地表不满足，所以原生环境不会长霉菌。
2. 只有人造封闭舱内部，人为创造温湿度条件，才会引入霉菌风险，沿用地球人居评估规则。
3. 地外评估增加独立风险维度：舱体结构完整性、辐射防护、低温材料老化、粉尘/液体侵蚀。

## 叶-舱体专项评估细则
1. 舱体为地外生存唯一核心屏障，任何结构性破损都标记为最高危险等级。
2. 舱内需持续监测温湿度、CO₂浓度，维持人居舒适区间。
3. 舱内巡检视觉识别清单：内壁凝露、管线渗漏、密封胶老化、微生物滋生。

## 月球栖息地环境规则

### 基础环境参数
- 重力：地球的 1/6
- 大气：极高真空（≈地球大气的万亿分之一）
- 昼夜周期：约29.5地球日（白天约14.75天，夜晚约14.75天）
- 表面温度：白天 +127°C，夜晚 -173°C
- 辐射：无全球磁场、无大气屏蔽，银河宇宙射线+太阳高能粒子直达表面
- 月尘：粒径细、棱角锋利、带静电、含微量有毒金属（纳米级二氧化硅）

### 核心风险因子
| 风险 | 权重 | 说明 |
|---|---|---|
| 辐射暴露 | 35% | 长期居住致癌风险，必须靠月壤/水冰屏蔽 |
| 月尘侵入 | 25% | 附着宇航服带进舱内，污染空气、损伤肺部、磨损密封件 |
| 温度极端波动 | 20% | 月夜长达14天，必须靠核反应堆或放射性同位素热源保温 |
| 气密性失效 | 15% | 微陨石撞击+月尘磨损导致舱体泄漏 |
| 低重力生理退化 | 5% | 长期1/6g导致骨密度流失、肌肉萎缩、前庭功能紊乱 |

### 操作规则
1. 月尘过滤系统：气闸室必须设双重吸尘+静电吸附，进舱前强制吸尘流程
2. 辐射规避：太阳耀斑预警时，人员撤入月壤覆盖的核心屏蔽舱（水冰/月壤堆积≥2米厚）
3. 月夜生存：月夜期间主舱转入低功耗模式，人员集中在核心生活区，减少舱外活动
4. 通风系统：过滤等级必须到HEPA级以上，专门拦截纳米级月尘颗粒

## 金星栖息地环境规则

### 基础环境参数（分两个方案）

#### 方案A：高空浮空站（50~60km高度，推荐）
- 大气压：约0.5~1个地球标准大气压
- 温度：0~50°C，接近地球宜居带
- 重力：与地球几乎一致（0.9g）
- 大气成分：96.5% CO₂ + 硫酸云 + 少量二氧化硫
- 优势：无需厚重加压舱，防护压力小；太阳能充足

#### 方案B：表面基地（高难度，仅科研用）
- 大气压：92个地球大气压（相当于水下900米）
- 表面温度：恒定462°C，足以熔化铅
- 大气：浓硫酸云层持续降落，腐蚀一切常见金属
- 必须用耐压+耐高温+抗腐蚀的特殊结构，机器人优先，人员短期驻留

### 核心风险因子（高空浮空站方案）
| 风险 | 权重 | 说明 |
|---|---|---|
| 硫酸大气腐蚀 | 30% | 外层外壳、太阳能板、观察窗长期被硫酸蒸气侵蚀 |
| 浮空器结构安全 | 25% | 气球/飞艇材料老化、穿孔导致高度下降坠入高温高压层 |
| 毒气渗入 | 20% | 二氧化硫、硫酸蒸气一旦漏入舱内，致命 |
| 通信延迟 | 15% | 金星-地球单程通信延迟约4~15分钟（视轨道位置） |
| 辐射 | 10% | 金星有厚厚大气屏蔽，表面辐射反而比月球低 |

### 操作规则
1. 外壳防护：浮空站外层必须用聚四氟乙烯（特氟龙）涂层抗硫酸腐蚀，定期更换外层蒙皮
2. 高度监控：实时监测浮空器高度，一旦下降到48km以下（温度急剧升高），立即启动应急补气
3. 空气过滤：新风系统必须带硫酸蒸气中和过滤层，舱内正压防止外界毒气渗入
4. 通信：关键操作（浮空、温控）必须本地自动控制，不能依赖地球远程指令（延迟太长）
5. 表面任务：人员上表面必须靠机器人先行侦察，驻留时间不超过数小时，返回后舱体全面检修

## 火星栖息地选址评估规则（陨石坑/近极地洼地优先方案）
> 适用：火星地表定居点选址评估，复用通用加权风险评估引擎；引擎无需改动，仅加载本套因子权重与规则。

### 基础背景
火星开阔大平原无天然遮蔽，宇宙射线直射，沙尘暴无遮挡。长期定居选址优先考量**陨石坑侧壁、近极地洼地**，利用本地岩土形成天然防护屏障，就近获取地下冰水。

### 权重分配（总分100）
| 评估因子 | 权重 | 说明 |
|---|---|---|
| 地下水资源/水冰储量 | 35% | 最高优先级；水是饮水、制氧、辐射屏蔽、生态循环的基础，无水冰不适合长期定居 |
| 宇宙辐射屏蔽条件（坑壁覆土厚度） | 30% | 坑壁岩土作为天然屏蔽层，覆土越厚，银河宇宙射线、太阳高能粒子削弱效果越好 |
| 风沙与沙尘暴风险 | 15% | 洼地/坑内可削弱风暴冲击力；评估粉尘沉积速率，粉尘会覆盖光伏、磨损舱体外表面 |
| 光照与能源供给条件 | 12% | 极地光照偏弱；太阳能为主时评估日照时长，预备核热源/核反应堆作为备用电源 |
| 地表温度、地质稳定性 | 8% | 评估昼夜极端低温、冻土活动、滑坡塌方风险；避开活跃断层、易滑坡坑壁 |

### 各因子评分细则
#### 1. 地下水资源/水冰储量（35分满分）
| 状态 | 得分 |
|---|---|
| 探明大量地下永久水冰，开采难度低 | 0~7 | 优秀 |
| 浅层少量水冰，开采需要简单挖掘 | 7~18 | 预警 |
| 仅深层地下水，开采成本极高 | 18~28 | 高风险 |
| 无水冰，水源需要远距离运输 | 28~35 | 极高风险，不推荐选址 |

#### 2. 宇宙辐射屏蔽条件（30分满分）
| 状态 | 得分 |
|---|---|
| 坑壁覆土≥2m，天然辐射防护达标 | 0~6 | 优秀 |
| 覆土1~2m，基础防护，需局部加厚 | 6~15 | 预警 |
| 覆土不足1m，辐射防护薄弱 | 15~24 | 高风险 |
| 无坑壁遮蔽，完全露天平原 | 24~30 | 极高风险 |

#### 3. 风沙与沙尘暴风险（15分满分）
| 状态 | 得分 |
|---|---|
| 坑内避风，粉尘沉降缓慢 | 0~3 | 优秀 |
| 洼地，沙尘暴期间少量积尘 | 3~8 | 预警 |
| 风口位置，大量粉尘堆积 | 8~12 | 高风险 |
| 完全迎风开阔地带，强沙尘暴持续冲击 | 12~15 | 极高风险 |

#### 4. 光照与能源供给条件（12分满分）
| 状态 | 得分 |
|---|---|
| 光照充足，光伏稳定，配套备用核电源 | 0~2 | 优秀 |
| 光照一般，冬季光照衰减，有备用热源 | 2~6 | 预警 |
| 光照弱，仅依靠核电源供电 | 6~10 | 高风险 |
| 长期阴影区，完全无法使用太阳能 | 10~12 | 极高风险 |

#### 5. 地表温度、地质稳定性（8分满分）
| 状态 | 得分 |
|---|---|
| 坑壁稳固，冻土稳定，温度波动可控 | 0~2 | 优秀 |
| 轻微冻土冻融，无滑坡风险 | 2~4 | 预警 |
| 坑壁存在小型滑坡隐患 | 4~6 | 高风险 |
| 地质不稳定，冻土崩塌风险高 | 6~8 | 极高风险 |

### 临时动态修正项（不计入基础权重，动态加分）
- 太阳耀斑预警：+8分风险，人员必须退入深层屏蔽舱
- 大型沙尘暴预报：+6分风险，收起外部光伏，舱体密闭检查

### 总分判定与输出模板
| 总分 | 风险等级 |
|---|---|
| <30 | 选址可行（低风险） |
| 30~50 | 选址有缺陷，需要改造优化 |
| 50~70 | 高风险，谨慎选址 |
| >70 | 极高风险，不建议在此选址 |

> 固定输出格式：

📌【辅助建议 1】第二优先级措施

### 冲突处理规则
1. 水源优先：就算辐射屏蔽条件一般，若本地具备大量易开采水冰，优先考虑；后续可人工加厚覆土增强屏蔽。
2. 露天否决：无坑壁遮蔽的开阔平原，直接拉高总分，不推荐长期定居。
3. 极端天象叠加：太阳耀斑、沙尘暴来临，临时切换核心操作，天象结束恢复基础评估。

### 示例场景
场景：火星某中型陨石坑，坑壁覆土约1.6m，浅层探明水冰，坑内避风，光照一般，地质稳定。

📌【辅助建议 2】配置核热源作为长期备用能源，应对冬季光照衰减

## 火星舱内密闭栖息地微环境评估规则
> 用途：评估封闭舱体内部人居环境，复用通用加权风险评估引擎，引擎不变，仅加载本套因子权重
> 定位：舱外选址完成后，舱内日常持续监测与风险评估

### 权重分配（总分100）
|评估因子|权重|说明|
|---|---|---|
|舱内气体组分与泄漏风险|35%|最高优先级。氧气、二氧化碳分压；舱体/管路气密性，气体泄漏属于致命风险|
|空气流通与风道循环状态|30%|风道堵塞、气流死角会造成局部CO₂富集、湿气堆积、污染物积聚|
|舱内温湿度与冷凝风险|20%|舱壁温差产生凝露，滋生微生物，腐蚀管路、电气设备|
|液体循环管路可靠性|10%|水循环管路渗漏、堵塞，会造成舱内进水、湿气超标|
